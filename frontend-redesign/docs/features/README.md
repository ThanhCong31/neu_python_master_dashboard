| Màn hình | Hồ sơ | Phạm vi |
|---|---|---|
| Tổng quan | [Overview](overview/README.md) | Tóm tắt theo quyền, báo cáo |
| Liên hệ & chuyển đổi | [Contacts](contacts/README.md) | Hồ sơ CRM và chuyển đổi |

Các hồ sơ giữ cấu trúc audit → API contract → design → plan → design review → acceptance (tùy tài liệu có sẵn). Đây là bằng chứng thiết kế theo baseline được ghi trong từng file, không phải tất cả đều là đặc tả hiện hành. Đối chiếu source và các quyết định mới hơn trong [history](../history/README.md) trước khi sửa code.
